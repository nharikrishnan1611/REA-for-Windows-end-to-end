# Windows Feature-Parity Matrix

This document provides the verified feature matrix for REA on Windows hosts, comparing baseline capabilities with implemented Windows extensions and alternatives for Hopper-dependent workflows.

| Feature Category                 | Target Type                         | Provider                                         | Host Requirements                      | Implementation                                                                          | Tests                                                                                           | Side Effects                                                      | Status                                      |
| :------------------------------- | :---------------------------------- | :----------------------------------------------- | :------------------------------------- | :-------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------- | :---------------------------------------------------------------- | :------------------------------------------ |
| **Native binary inventory**      | PE (x86, x64, ARM, ARM64), Raw 6502 | Ghidra (`ghidra`)                                | Windows 10+ x64, JDK 21+, Ghidra 12.1+ | `GhidraClient.ts`, `GhidraInventoryValues.ts`                                           | `GhidraProvider.behavior.test.ts`                                                               | Ephemeral temporary project created outside target                | **Verified Supported**                      |
| **Assembly & decompilation**     | Native PE binaries                  | Ghidra (`ghidra`)                                | Windows 10+ x64, JDK 21+               | Listing disassembly & Ghidra Decompiler bridge                                          | `GhidraFunctionValues.test.ts`, `GhidraProvider.behavior.test.ts`                               | CPU/memory during decompilation                                   | **Verified Supported**                      |
| **Ghidra navigation & GUI**      | PE                                  | None                                             | N/A                                    | Ghidra headless runs without GUI control; navigation is address/offset-based            | `GhidraInventoryValues.test.ts`                                                                 | None                                                              | **Unsupported by design** (No GUI control)  |
| **Function renaming & comments** | Native PE                           | Ghidra (`ghidra`) + `@rea/windows-parity/ghidra` | Windows 10+ x64                        | Ephemeral session edits in Ghidra; authorized via `REA_ALLOW_WINDOWS_GHIDRA_MUTATION=1` | `WindowsGhidraCapabilities.test.ts`, `GhidraProviderCapabilities.test.ts`                       | Ephemeral database metadata edits; **never patches binary bytes** | **Verified Supported (Authorized)**         |
| **Annotation persistence**       | Any binary (PE, ELF, Mach-O)        | `@rea/windows-parity/persistence`                | Cross-platform / Windows NTFS          | `AnnotationStore.ts`: Durable JSON store keyed by binary SHA-256                        | `AnnotationStore.test.ts`, `WindowsAnnotationStore.test.ts`                                     | JSON metadata written strictly to isolated storage directory      | **Verified Supported**                      |
| **Windows UI Automation**        | Running Windows desktop processes   | `@rea/windows-parity/ui` (`native-windows`)      | Windows 10+, UI Automation assemblies  | `WindowsUiObserver.ts`: Traverses accessible controls, roles, names, bounds, patterns   | `WindowsUiObserver.test.ts`, `WindowsUiObservation.test.ts`, `WindowsUiRealIntegration.test.ts` | Strictly read-only; no code injection, no memory patching         | **Verified Supported**                      |
| **Screenshot capture**           | Running Windows desktop windows     | `@rea/windows-parity/ui`                         | Windows 10+, GDI / Desktop composition | `WindowsScreenshot.ts`: Window bounds capture to PNG, width/height, SHA-256             | `WindowsScreenshot.test.ts`, `WindowsUiRealIntegration.test.ts`                                 | Visual frame buffer capture                                       | **Verified Supported**                      |
| **Browser inspection**           | Chromium, Chrome, Edge              | CDP (`cdp-browser`)                              | Node.js, remote debugging port         | `src/browser/`                                                                          | `browserObservation.test.ts`                                                                    | Connects via WebSocket to target CDP port                         | **Verified Supported**                      |
| **Electron inspection**          | Electron apps on Windows            | CDP / Playwright                                 | Node.js                                | `src/electron/`                                                                         | Electron test suite                                                                             | Connects via debugging port                                       | **Verified Supported**                      |
| **Runtime observation**          | Mach-O only (macOS LLDB)            | `native-macos`                                   | macOS only                             | LLDB call tracer                                                                        | LLDB test suite                                                                                 | Process execution under debugger                                  | **Host Unavailable** (macOS only)           |
| **Hopper-specific GUI**          | Mach-O / macOS binaries             | `hopper`                                         | macOS only, Hopper v4 license          | AppleScript / Hopper bridge                                                             | Hopper test suite                                                                               | Hopper application execution                                      | **Host Unavailable** (Hopper is macOS-only) |
| **Provider diagnostics**         | All providers                       | `rea doctor`, `WindowsAuthority.ts`              | Windows 10+                            | Doctor checks, native readiness inspection                                              | `doctorRuntime.test.ts`, `WindowsNativeLoader.test.ts`                                          | None                                                              | **Verified Supported**                      |
